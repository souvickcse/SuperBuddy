## Description

Bring your Mac desktop to life with four selectable superhero buddies. Watch them
swing, glide, drive up walls and battle baddies. Set the pace, pick a display, or
trigger actions from the menu bar. Free for macOS 13+, with source code on GitHub.

## Maker's first comment

Hi Product Hunt! I built Super Buddy to bring a little playfulness to the Mac desktop.

Choose Spider-Buddy, Pool-Buddy, Bat-Buddy or Smash-Buddy. Each has its own movements,
actions and baddies. Spider-Buddy swings and crawls around the screen, while
Bat-Buddy has a grappling cable, a bat swarm and a Buddy-Mobile that races up the
screen edges.

You can drag and drop your buddy, trigger actions from the menu bar, choose a
display and size, and set how often automatic actions and baddies appear. The rest
of the desktop stays clickable. It runs locally, with no account required.

Super Buddy is free for macOS 13+ on Apple Silicon and Intel. Install through
Homebrew or grab the GitHub release. The source and contributor guide are there too
if you want to add another buddy or animation. The current build is ad-hoc signed,
so first launch may need Open Anyway in macOS Privacy & Security.

The gallery comes from my recording of the running app. I would love feedback on
the animation variety, the default action intervals, and which buddy you would like
to see next.
